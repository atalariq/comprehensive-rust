## Tentang

Segmen ini menjelaskan pinning, tipe `Pin<Ptr>` dalam Rust, dan konsep yang berkaitan
dengan FFI alih-alih use case async-nya. Pembahasan trait `Unpin` dan
tipe `PhantomPinned` disertakan.
